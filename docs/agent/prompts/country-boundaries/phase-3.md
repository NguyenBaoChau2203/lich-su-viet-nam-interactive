## Work item — prove the additive change

**Problem:** A successful render can conceal optional-loading regressions, missed geographic payload, shared-edge artifacts or continuing idle work.

**Required change:** Follow B3. Test the retained event/filter/detail/history/intro/journey/fallback flows plus boundary pixel/occlusion/failure cases. Capture all four desktop sizes and source-derived line samples. In a separate quiet measurement window, compare matched boundary-off/on flight frames, draw calls, buffer allocation, transfer, idle/hidden and repeated disposal. **Acceptance criteria:** Added draw calls ≤1; segments ≤60,000; added geometry target ≤4 MiB; data gates met; median frame interval ≤33.3 ms and p95 ≤50 ms on the disclosed configuration; no new live context or continuing idle/hidden draws. Optional source failure leaves usable Earth/events and no stale attachment. Current event/URL/race and accessibility regressions pass. Do not claim historical-border coverage or close-texture parity.

**Verification:** Run new unit tests, all five selected read-only public homepage suites, `pnpm verify`, diff/status and notice/source inspection. Do not run mutation-oriented unrelated E2E against a connected live service. Report exact selection, configuration and limitations.
